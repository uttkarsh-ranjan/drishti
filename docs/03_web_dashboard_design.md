# Web Dashboard Design & Implementation

## 1. Overview
The web dashboard serves as the central command centre for DoSJE officials and department admins. It provides real-time visibility into inspections, live CCTV feeds, and AI-flagged anomalies.

## 2. Technology Stack
- **Framework**: React.js
- **Language**: TypeScript
- **Video Streaming**: WebRTC (via LiveKit and MediaMTX WebRTC adaptors)
- **State Management**: Redux or Context API
- **Styling**: TailwindCSS or Material-UI

## 3. Core Features & Implementation Plan

### 3.1. Multi-Feed Command Centre
- **Live CCTV Integration**: The dashboard consumes WebRTC streams provided by the MediaMTX multiplexer. This ensures plugin-free, sub-500ms latency viewing directly in the browser.
- **Grid View**: Officials can view multiple RTSP feeds from different NGOs simultaneously in a grid layout.

### 3.2. Surprise Virtual Audits (Video Conferencing)
- Integration with **LiveKit SDK** enables officials to instantly initiate peer-to-peer video calls with facility staff or beneficiaries.
- Uses per-session DTLS keys for secure, end-to-end encrypted communication.

### 3.3. Anomaly & Risk Alerts
- The dashboard listens for anomalies generated by the asynchronous AI pipeline (Celery workers).
- **Explainable AI (SHAP)**: High-risk flags (e.g., proxy attendance, crowd discrepancy) are displayed with SHAP (SHapley Additive exPlanations) values to explain *why* the AI flagged the event. This mandates human review before any punitive action.
- Alerts categorize issues such as "Evidence Falsification", "Proxy Beneficiary", or "Geofence Violation".

### 3.4. Accountability & Corrective Actions
- Officials can review geo-tagged, time-stamped inspection reports submitted by the Flutter app.
- Includes a corrective action tracker where officials can assign tasks to NGOs to rectify non-compliance, with specific deadlines.

## 4. Role-Based Access Control (RBAC) UI
The UI adapts based on the logged-in user's JWT payload:
- **DoSJE Officials**: Global view, access to all NGOs, CCTV feeds, anomaly alerts, and ability to initiate VC.
- **PMU Inspectors**: View their historical inspection logs and metrics.
- **NGO Admins**: Access to a compliance portal to upload documents, register cameras, and respond to corrective actions.
